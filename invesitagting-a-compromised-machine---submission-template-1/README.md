# Investigating a Compromised Windows Machine

**SOC Analyst Portfolio Project · Incident Investigation**

## Overview
Investigated a simulated compromised Windows endpoint by correlating authentication, audit-log, process and network evidence.

## Key Findings
- Identified suspicious failed-login activity followed by a successful login inconsistent with the expected user schedule.
- Identified deletion of audit logs as a potential defense-evasion indicator.
- Investigated `sshd.exe` activity and considered potential command-and-control communication.
- Documented follow-up questions covering privilege escalation, first C2 communication and additional malicious files.
