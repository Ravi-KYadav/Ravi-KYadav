# Nmap Network Scanning & Windows Firewall Lab

> **SOC Analyst Portfolio Project**

## Overview
Performed network discovery and service-scanning exercises and compared results before and after Windows Firewall configuration.

**Category:** Network reconnaissance / defensive monitoring  
**Tools / Concepts:** Nmap / Windows Firewall / network discovery

## What I Did
- Performed network discovery scans across the lab subnet.
- Performed Nmap scans with firewall enabled and compared observable results.
- Reviewed Windows Firewall logs to understand blocked traffic and scan behavior.
- Used scan results to connect reconnaissance activity with defensive controls.
