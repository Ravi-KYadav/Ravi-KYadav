# MITRE ATT&CK Framework Analysis

> **SOC Analyst Portfolio Project**

## Overview
Mapped threat-actor and malware behaviors to MITRE ATT&CK tactics, techniques and sub-techniques.

**Category:** Threat intelligence / adversary TTP mapping  
**Tools / Concepts:** MITRE ATT&CK / ATT&CK Navigator / TTPs

## What I Did
- Analyzed Lazarus Group activity and its ATT&CK-related behaviors.
- Mapped Tropic Trooper behaviors including Native API (T1106), Process Discovery (T1057) and User Execution (T1204).
- Documented DNS-based command-and-control behavior and related ATT&CK mapping.
- Linked adversary behaviors to tactics and detection/mitigation considerations.
