# NotPetya Incident Response Report — A.P. Møller-Maersk

**SOC Analyst Portfolio Project · Incident Response & Threat Reporting**

## Overview
Produced an analyst-style incident report covering classification, timeline, scope, affected systems and remediation for the NotPetya incident scenario.

## Key Areas Covered
- Incident classification and priority
- Timeline and global scope
- Containment and system isolation
- Restoration and rebuilding
- Patching and vulnerability management
- Forensic investigation and remediation

## Analyst Perspective
The report focuses on how a SOC/security team can move from incident identification through containment, recovery and long-term risk reduction.

Selected evidence screenshots are included in this project folder.

## Scope
Educational incident-response research and reporting exercise.
