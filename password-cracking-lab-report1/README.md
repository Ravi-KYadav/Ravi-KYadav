# Password Security & Hash Cracking Lab

**SOC Analyst Portfolio Project · Credential Security**

## Overview
Performed controlled password-security exercises against lab credentials using multiple password-auditing tools.

## What I Did
- Analyzed NTLM password hashes in a controlled Windows lab.
- Performed NTLM hash recovery exercises with Ophcrack on Kali Linux.
- Used John the Ripper against supplied lab hashes.
- Compared outcomes across password-auditing approaches.

## Skills Demonstrated
NTLM · password security · credential auditing · Kali Linux · L0phtCrack · Ophcrack · John the Ripper

## Evidence
Public evidence intentionally redacts recovered password values.

## Scope & Ethics
Only controlled lab credentials were used. No real credentials or unauthorized systems were targeted.
