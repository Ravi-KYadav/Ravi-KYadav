# Phishing Email Analysis

**SOC Analyst Portfolio Project · Email Security & Social Engineering**

## Overview
Analyzed email samples to distinguish legitimate messages from phishing attempts using sender, message and hyperlink evidence.

## What I Did
- Reviewed sender and message characteristics for phishing indicators.
- Analyzed hyperlinks and destination behavior to assess authenticity.
- Documented reasoning and evidence for each assessment.
- Validated a legitimate Dropbox-related message by checking its link destination in the lab exercise.

## Skills Demonstrated
Phishing analysis · email security · URL analysis · social-engineering detection · IOC identification

Selected evidence screenshots are included in this project folder. Sensitive values are not intentionally published.

## Scope & Ethics
Educational email-analysis exercise. Live malicious attachments and unauthorized phishing activity are not part of this portfolio.
