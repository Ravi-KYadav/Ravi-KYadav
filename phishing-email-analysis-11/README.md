# Phishing Email Analysis

> **SOC Analyst Portfolio Project**

## Overview
Analyzed email samples to distinguish legitimate messages from phishing attempts using message and hyperlink evidence.

**Category:** Email security / social engineering  
**Tools / Concepts:** Phishing analysis / email headers / URLs / IOCs

## What I Did
- Reviewed sender and message characteristics for phishing indicators.
- Analyzed hyperlinks and destination behavior to assess authenticity.
- Documented reasoning and evidence for each email assessment.
- Validated a legitimate Dropbox-related message by checking its link destination in the lab exercise.
